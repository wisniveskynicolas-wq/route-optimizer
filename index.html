Route Optimizer

Orders your stops to minimize drive time using Google's traffic data, plots the route, and flags the stops that add the most driving.

Google API key (needed for optimization and the map)
Stored only in this browser. Enable the Routes API and the Maps JavaScript API (for the map) on the key, plus the Geocoding API only if you use street addresses on runs over 25 stops. Stops given as coordinates (lat, lng) need no Geocoding API. Without a key, the tool still builds a Google Maps link in the order you typed.

One-time setup
  1. Open this page from a web address, not a local file: run python3 -m http.server 8000 in this folder and visit http://localhost:8000, or host it on GitHub Pages.
  2. In Google Cloud, enable the Route Optimization API for your project.
  3. Go to APIs & Services, then OAuth consent screen. Choose External, fill in the basics, and add your own Google account under Test users.
  4. Go to Credentials, then Create credentials, then OAuth client ID. Type: Web application. Under Authorized JavaScript origins, add the address from step 1 (for example http://localhost:8000).
  5. Paste the client ID and your project ID above, then press Sign in with Google. Sign in again about once an hour.
